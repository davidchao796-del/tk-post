Privacy Policy

TK Post respects user privacy and complies with TikTok Developer Policies and OAuth 2.0 standards.

1. Data Collection

We only collect data explicitly authorized by users via TikTok OAuth, including:

  • Basic profile information (nickname, avatar, open_id)
  • Public video list (if user grants permission)

2. Data Usage

All data is used strictly for:

  • User authentication
  • Displaying authorized account information
  • Content management and analytics inside the application

3. Data Protection

We do not sell, rent, or transfer any user data to third parties. All data access is strictly limited to the scope authorized by the user.

4. Data Storage

We do not permanently store TikTok user data unless explicitly required for application functionality.

5. User Rights

Users may revoke TikTok authorization at any time through TikTok account settings.

6. Compliance Statement

This application does not perform scraping, automation abuse, or unauthorized data collection. All access is based on TikTok official APIs.
